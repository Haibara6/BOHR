# 异常处理（降级模式）

遇到异常要**明确说明原因与可人工接管位置**，不伪造、不硬编、不静默跳过。

## 材料形态判定与处置

| 形态 | 处置 |
|-|-|
| 有文字层 PDF | `pdf-text-tool` 抽取；校验文字完整度（无大段空白/乱码） |
| 扫描件 / 无文字层 | `pdf-render-tool` 逐页渲染 PNG → `ocr-tool` 识别；OCR 不确定处标 `【待核】` |
| 公式/表格为图片 | 渲染区域 → 转写并在 `uncertain` 标注"图片/OCR 转写，需人工核对"；无法可靠转写则写"未翻译" |
| 参考文献无法解析 | 原样保留原始字符串，`limits.unparsed_references=true` |
| 原文残缺 / 语言混杂 | 逐段标注语言与完整度，只译可识别部分，其余标 `【无法判断】` |
| LaTeX 源 | 用 `latex-compiler` 或直接读 `.tex`，公式保留原 LaTeX |

## 运行异常

| 情形 | 处置 |
|-|-|
| 工具不可用（如无 OCR） | `status=partial/unable`，写明缺哪个工具、哪些页未处理 |
| 预算耗尽/超时（64 请求 / 900 s） | 立即落 `status=partial` 的 `result.json`，列已完成与剩余段号 |
| 中断/失败 | 保留已完成段，写 `change_records`，不重头重做已完成部分 |
| 材料缺失 | `status=unable`，写缺失文件与可人工接管位置 |

## 铁律

- 不依据错误的领域标签补造数据；原文没写的就写"未报告/无法判断"。
- 无法判断不被写成事实。
- 任何异常都写进 `status_reason` 或 `uncertainty`/`limits`，评审据此复核。
